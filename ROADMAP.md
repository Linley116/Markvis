## 五、已知限制（面向使用者）

- **表格单元格不能放段落**：换行已支持，Enter / Shift+Enter 写入 `<br>`，但 Markdown 表格仍不支持单元格内多段。
- **HTML 块只按顶层拆页**：PDF 会按顶层块元素分段，但单个不可拆元素超过一页时可能被页底裁掉；脚本在预览和导出中都不执行。
- **只提供源码**：仓库没有预编译或已公证的二进制，请按 README 自行构建；`release.sh` 的 DMG 仅供本机或内部使用。

## 六、工程踩坑记录

**1. WebKit 的两条打印路径都不可用（实测，不是猜）**
`WKWebView.printOperation(with:)` 产出约 10 万页空白；`NSPrintOperation(view:)` 页数正常但每页全白（WebKit 内容在独立进程渲染）。所以只能自己做版面。

**2. WKWebView 一次只能授一个读取目录**
`loadFileURL(_:allowingReadAccessTo:)` 只接受一个根目录，而 `index.html` 在 bundle 里、文档在别处。
解法：把访问根放宽到两者的公共祖先（跨盘时是 `/`）并整页重载；重载期间到达的打开请求要排队，且新请求要能顶掉旧排队。

**3. 原生标签组会「吞掉」窗口**
`tabbingMode = .preferred` 时新窗口可能被系统自动并入标签组，`CGWindowList` 里只看得到 **一个** 窗口——别据此误判窗口没建出来。判断方式是看 `NSWindow.tabbedWindows`。

**4. `.md-meta` 展开/收起不能「先删类再加类」**
同一帧里 `display` 闪一次 `none→inline`，Blink 的插入符位置缓存会失效，方向键随后整块跳过标记。只能动真正需要变的元素。

**5. 源码偏移与标记的边界**
偏移正好等于标记末尾时，光标要落到 **下一个** 文本节点（内容开头）；否则会停在隐藏标记里，按左方向键直接跳出整个行内元素。

**6. 懒加载资源的字体路径**
KaTeX 的 CSS 用相对 `url(fonts/…)`：PDF 导出要把 `fonts/` 拷进打印壳目录；独立 HTML 导出则把字体 base64 内联，保证单文件可移植。

**7. 嵌套容器不要用「渲染时快照」的 data-src**
一开始给嵌套列表/引用挂了 `data-src`（渲染时算好的源码），结果在嵌套列表里打字，
序列化读到的还是旧文本 —— 改动全部丢在快照里。现在序列化一律读实时 DOM，
光标遍历则当场 `blockRaw(node)` 算长度。

**8. 空段落没有光标位置**
多块条目里「段末回车」生成的空 `<p>`，Chrome 放不进光标（DOM 里看着在，
一输入就落到隔壁段）。必须给它补一个 `<br class="md-pad">` 占位，
所以 `ensurePlaceholder` 要递归进嵌套容器。

**9. 面板开关别压住面板自己的按钮**
文件树开关在右上角，面板展开时会盖住面板头部的按钮。做法是展开时把开关挪到面板外侧
（`right: calc(var(--mf-lib-w) + 10px)`）并加 `transition: right`，两个开关共用 `.mf-fab` 一套外观。

**10. Command Line Tools 不带 XCTest，但带 Swift Testing**
本机只有 CLT 时，`swift test` 编译 XCTest 目标会报 `unable to resolve module dependency: 'XCTest'`；Swift Testing 又有宏插件路径问题。所以原生测试拆成「共享场景 + 两种入口」：完整 Xcode 下由 XCTest 调场景，CLT 下用 `swiftc` 编一个十几行的运行器调同一组场景。不要为了跑测试去装完整 Xcode，也不要让两边各写一份断言。

**11. 主题元信息只认「独立单行指令」**
`@name` 用宽松正则会在示例文件开头的说明注释里误命中（那行也写着 `@name : …`），
菜单里显示的是整句说明而不是主题名。现在只接受 `/* @name: x */` 这种独占一行的注释，
或裸写的 `@name: x`；JS 与 Swift 两端用同一套规则，否则菜单名和按钮名会对不上。

**12. CI 上不要用固定延迟等异步结果**
PDF 回归原来 `sleep 14`，本机够用，CI 上文件还没写完就判失败。改成等文件出现且大小连续两秒不变（最多 90 秒）。更隐蔽的是应用内的自动导出钩子：固定 1.8 秒后才开始，CI 上 Web 层还没加载完，分页只得到 1 页且内容被截断。现在轮询 `document.readyState`、`__prepareExport`、`__paginateForPrint` 都就绪再导出。经验：测试里的 `sleep` 只能在“最多等多久”上使用，不能当作“已经完成”的判据。
